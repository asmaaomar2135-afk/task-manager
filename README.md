# 📋 Smart Task Manager | مدير المهام الذكي

تطبيق ويب حديث وبسيط لإدارة المهام اليومية وحفظها محلياً، مصمم باستخدام **Tailwind CSS** و **JavaScript**.

## ✨ المميزات
- ➕ إضافة مهام جديدة بسهولة.
- ✅ تعليم المهام كمكتملة.
- 🗑️ حذف المهام.
- 💾 حفظ تلقائي للمهام في المتصفح (LocalStorage).
- 📱 تصميم عصري ومتجاوب بالكامل مع جميع الشاشات.

## 🛠️ التقنيات المستخدمة
- **HTML5**
- **Tailwind CSS** (تصميم الواجهات)
- **JavaScript (ES6+)** (المنطق والتعامل مع LocalStorage)

## 🚀 كيفية التشغيل
1. قم بتحميل الملفات أو عمل `git clone` للـ Repository.
2. افتح ملف `index.html` في أي متصفح مباشرة دون الحاجة لـ Server!
